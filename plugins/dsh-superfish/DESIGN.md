# 设计约定

1. **宿主融合与布局规范**：使用 DSH 原生主页面与侧栏槽位，保留宿主导航和会话布局；首次进入默认聚焦大肥鱼主面板，支持同页会话对话与右侧可折叠四栏个人工作台（**工作概览 / 记忆库 / 技能库 / 主理配置**）。
2. **视觉与主题语义**：采用系统无衬线字体、主题背景与细边框，所有色彩与层级均引用宿主 `--dsw-*` 语义 token，完整适配亮/暗主题与窄屏响应式布局。
3. **生成式卡片与确认边界**：会话内嵌快捷操作提案卡（看板建卡、定时任务）与 OpenTiny GenUI 可视化卡片；所有写看板、创定时与 `workspace-write` 派工操作均遵循“AI 草案准备 -> 用户核对/确认 -> 幂等提交与回执核实”的受控交互范式。
4. **可观测性与无障碍**：依赖缺失、授权到期与宿主连接状态在健康页与面板顶部明确可见；关键交互控件具备完整 `aria-label` 与状态读屏语义。
